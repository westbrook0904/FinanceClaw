# 当前架构决议

1. 使用 Python 3.13、LangChain、LangGraph Agent Server 和 LangSmith。
2. BFF 是产品与业务安全入口，负责会话、运行控制、人工决定及 Journal。
3. 顶层 ReAct 通过 Tool 调用叶子能力和内部 subgraph，领域 Agent 与 Workflow 不独立创建业务运行。
4. 业务事实使用同一数据库；原生 checkpoint/store 由 Agent Server 管理。
5. Webhook 是 BFF 的持久唤醒入口，后台核对独立于客户端连接。
6. 权限、审批、预算、制品、长期记忆与审计保留领域约束；历史记忆不能替代实时金融事实。
7. 尚未上线，数据库以当前初始 schema 为基线；不维护被删除架构的升级兼容。

详细边界见 [当前架构](00-最终架构设计.md)和 [Hotfix 实施方案](stages/stage-8-hotfix-实施方案.md)。

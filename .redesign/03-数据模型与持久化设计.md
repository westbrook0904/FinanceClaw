# Stage 11 数据模型

> 适用范围：重构阶段的设计汇总，保留当时决议；当前实现与操作请阅读[数据归属与术语](../docs/architecture/package-layout.md#数据归属与常见术语)，其他历史记录见[档案索引](README.md)。

API、Worker、integrations、memory_worker 按不同权限使用应用库；原生运行和 checkpoint/Store 位于独立的 LangGraph 原生库。`0001_initial` 只用于空应用库，ORM 与迁移共 18 张业务表，不管理原生 schema。

| 责任 | 表 |
|---|---|
| 会话与原文 | conversations、channel_conversation_bindings、conversation_messages |
| 运行事实 | conversation_turns、turn_commands、interactions |
| 模型输入证据 | model_context_manifests |
| 工件、审计与消费意图 | artifacts、audit_records、outbox_events |
| 通知与投递 | notification_targets、notification_events、notification_deliveries、notification_senders |
| 记忆事实与派生 | memory_owners、memory_sources、memory_extractions、memory_records |

Turn 保存冻结发布与输入、有限 grant、累计预算、当前 command 和观察租约。Command 保存不可变请求/hash、发送状态和真实 native_run_id。Interaction 绑定原命令、完整 checkpoint、interrupt 与唯一决定。

受理以一个事务写 user Journal、Turn、start command、授权审计、通知目标与记忆来源。人工回答原子写决定、来源、收窄后的授权和新 resume command。最终结果核对以一个事务写 observed command、最终 assistant Journal、状态/revision、审计、通知、历史索引与闭合记忆提取意图。

memory_sources 只保存来源引用、版本/hash、顺序与有限许可；提取正文位于有范围和状态的 memory_extractions。memory_records 追加事实/候选版本，memory_owners 保存 owner 版本、隐私屏障及整合指针。记忆变更、审计回执、通知和索引意图同事务提交；Outbox 复用持久预算和续租元数据。用户级记忆审计可无 turn_id，真实执行审计仍必须有 Turn。

组合外键保证 current command、输入消息和 interaction 都属于同一 Turn。原生 run 回执唯一；每会话最多一个非终态 Turn；每 Turn 只有一个 start 和一个待回答交互。PostgreSQL 的延迟外键允许原子写入相互引用的 Turn、输入和命令。

sending 权利不可回收；lease_owner/epoch/until 仅分配观察责任。过期租约可以重领，陈旧观察不能写结果。授权历史和控制幂等回执复用 audit_records，不另设 grant/Inbox 表。SSE 不持久化进度历史。

# 当前持久化设计

业务库由 BFF 与 Agent Server 共享。Alembic `0001_initial` 与 ORM metadata 一致，初始化 22 张表。

| 领域 | 表 |
|---|---|
| 会话与上下文 | conversations、conversation_turns、conversation_messages、conversation_summaries、model_context_manifests、channel_conversation_bindings |
| 执行 | run_executions、run_operations、root_runs、backend_attempts、run_progress_events |
| 授权与恢复 | run_authorizations、pending_interactions、run_inbox、run_control |
| 制品与审计 | artifacts、audit_records、outbox_events |
| 通知 | notification_targets、notification_events、notification_deliveries、notification_senders |

一个业务 Turn 只有一个根执行，数据库约束 root_run_id 等于 run_id。子图共享根预算，原生 attempt 表示 start 或人工 resume，不表示子任务。

BFF 受理在一个事务内写 user Journal、Turn、发布快照、有限授权、operation 和唤醒线索。完成核对在一个事务内写 attempt、assistant Journal、Turn、进度、Audit 和通知意图。Webhook 只保存认证后的最小线索，不能成为完成证据。

永久 Journal 保存原文；提示词使用预算、摘要与相关历史选择。制品正文由 Artifact Store 保存，业务库保存元数据。原生 Thread/Run/Checkpoint 和长期 Memory Store 的持久化由 Agent Server 部署负责。

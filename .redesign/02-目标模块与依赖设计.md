# 模块与依赖设计

项目由 BFF 与 Agent Server 两个服务组成。通知发送器属于 BFF 包，可作为独立进程运行。

```text
financeclaw/
  bff/
    application/           会话、飞书入站与根运行用例
      runs/                start、resume、cancel、授权、租约、结果核对
    http/                  产品 API、SSE 与 Webhook 接收
    channels/              飞书 WebSocket 适配
    notifications/         持久通知发送
  agent_server/
    agents/                顶层 ReAct 与领域模型装配
    graphs/                唯一产品根图和内部 Worker 子图
    tools/                 叶子 Tool 与 subgraph Tool
    middleware/            权限、审批、预算、重试和上下文
    domains/               金融及紫微领域能力
    context/  memory/  llm/
  kernel/                  跨服务数据契约
  shared/
    releases/              当前发布声明与不可变 Worker manifest
    conversation/          BFF 控制的永久聊天记录
    execution_ledger/      根执行、操作、授权和交互事实
    backends/              原生 Agent Server 出站适配
    artifacts/  audit/  notifications/  outbox/  infrastructure/
  operations/  evaluation/
```

依赖规则：BFF 和 Agent Server 只依赖本包、kernel 和 shared；shared 只依赖自身和 kernel；kernel 不反向依赖服务。BFF 不导入 AgentFactory、执行图或领域引擎。两个服务按同一发布配置装配静态声明。

业务库包含 Journal、执行与授权、交互、制品元数据、审计和通知。Agent Server 另行管理原生 Thread、Run、Checkpoint 和 Store。Worker 调用始终使用根业务身份和预算，不创建独立业务运行或原生 Thread。

产品图只注册 `finance_agent_v1_6_0`。`call_agent__*`、`call_workflow__*` 是根 ReAct 的 Tool，在同一 Agent Server 进程内调用 subgraph；正常返回 ToolMessage，人工等待通过根运行的原生 interrupt/resume 完成。
